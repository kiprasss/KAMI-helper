# KAMI Helper

Оверлей поверх игры для поиска по правилам NOVA RP: общие правила проекта и законодательство выбранного сервера (NEW ERA, MIRAGE, HORIZON).

Правила берутся прямо с форума forum.nova-rp.com — так же, как это делает Discord-бот NOVA RP AI. База данных не нужна.

## Как это работает

1. `backend` (Go) при запуске и затем каждые 2 часа обходит разделы форума:
   - общие правила: `forums/893` (со всеми подразделами) и `threads/403338` (правила подачи жалоб);
   - законодательство: NEW ERA — `forums/1320`, MIRAGE — `forums/929`, HORIZON — `forums/1478`.
2. Если форум показывает «Проверка браузера», backend открывает страницу в настоящем headless Chrome/Chromium/Edge, ждёт, пока проверка пройдёт, и дальше ходит на форум с полученными cookie. User-Agent честный, пауза между запросами — 1 секунда.
3. Темы разбираются на пункты правил («4.1 Текст | JAIL 60 минут») и на фрагменты текста. Поиск — BM25 с упрощённым русским стеммером и словарём игрового сленга (ДМ, ЗЗ, НРП, фама и т. д.).
4. Всё скачанное сохраняется в `backend/data/forum-cache.json`, поэтому после перезапуска поиск работает сразу, а форум повторно не нагружается.

## Запуск backend

Нужен Go 1.27+ и установленный Chrome, Chromium или Microsoft Edge (на Windows Edge есть всегда).

```bash
cd backend
go run ./cmd/api
```

Первая загрузка правил занимает несколько минут — приложение в это время показывает «База правил загружается с форума…».

Тесты: `go test ./...`

### Настройки (`backend/.env`)

| Переменная | По умолчанию | Что делает |
|---|---|---|
| `PORT` | `8080` | Порт API |
| `FORUM_BASE_URL` | `https://forum.nova-rp.com` | Адрес форума |
| `SCRAPER_USER_AGENT` | `KAMI-Helper/1.0 (NOVA RP rules search)` | User-Agent запросов к форуму |
| `SCRAPE_DELAY_MS` | `1000` | Пауза между запросами к форуму |
| `SCRAPE_CACHE_MINUTES` | `30` | Тема, скачанная недавно, повторно не скачивается |
| `REFRESH_MINUTES` | `120` | Как часто обновлять правила |
| `SCRAPE_MAX_THREADS_PER_SOURCE` | `60` | Сколько тем брать из одного раздела |
| `SCRAPE_FORUM_PAGES` | `2` | Сколько страниц списка тем смотреть в разделе |
| `SCRAPE_MAX_PAGES_PER_THREAD` | `3` | Сколько страниц читать в одной теме |
| `FORUM_BROWSER_CLEARANCE` | `true` | Проходить «Проверку браузера» через Chrome |
| `FORUM_BROWSER_PATH` | — | Путь к Chrome/Chromium/Edge, если он не найден автоматически |
| `CACHE_FILE` | `data/forum-cache.json` | Файл с сохранённой базой |
| `CORS_ORIGINS` | адреса Tauri | Разрешённые источники запросов, через запятую |
| `FORUM_GENERAL_SOURCES` | `forums/893`, `threads/403338` | Ссылки на общие правила, через запятую |
| `FORUM_SERVERS` | три сервера NOVA RP | `КОД\|Название\|ссылка,ссылка;КОД\|...` |

## API

- `GET /api/v1/servers` — список серверов
- `GET /api/v1/status` — состояние базы (загружается, обновляется, форум закрыт проверкой)
- `GET /api/v1/search?q=дм&server=MIRAGE&limit=30` — поиск
- `GET /api/v1/rules/{id}` — полный текст пункта или фрагмента и ссылка на сообщение форума

## Запуск приложения

```bash
cd desktop
npm install
npm run tauri dev
```

Сборка установщика: `npm run tauri build`.

Если backend запущен не на этом компьютере, создайте `desktop/.env` с `VITE_API_URL=https://ваш-адрес/api/v1` (по `.env.example`). Для адреса по `http://` (не `https://`) добавьте его в `connect-src` в `desktop/src-tauri/tauri.conf.json`.

### Горячая клавиша

По умолчанию F4. Можно назначить F1–F24, Insert, Home, End, PageUp, PageDown, Pause, ScrollLock или любое сочетание с Ctrl / Alt (например Ctrl+Shift+K). Одиночные буквы и цифры запрещены — они перехватывались бы во всей системе и мешали набору текста. Клавиша определяется по физической кнопке, поэтому работает при любой раскладке.
